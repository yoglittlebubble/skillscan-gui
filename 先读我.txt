SkillSpector 体检台 v1.1  —— 装之前看一眼
==================================================

这是什么
--------
扫描 AI skill（给 Claude Code / Codex / DSH 之类用的那种技能包）是否安全的工具。
填一个 GitHub 地址或本地文件夹，它告诉你这个 skill 里有没有偷凭据、
往外发数据、提权、提示词注入这类问题。


怎么装（3 步）
--------------
1. 把整个压缩包解压到一个你找得到的地方（比如 D 盘，别直接双击压缩包里的程序）
2. 双击  安装.bat
3. 等它跑完（大约 1-2 分钟），桌面会出现「SkillSpector 体检台」

装完是离线可用的：Python 运行环境和扫描引擎都打包在压缩包里，不需要你另外装
Python、不需要联网、不需要管理员权限。


可能会遇到的两件事
------------------
1. 如果弹出「Windows 已保护你的电脑」
   → 点「更多信息」→「仍要运行」。这是没买代码签名证书的正常现象。

2. 如果安装窗口一闪就没了
   → 说明 PowerShell 被策略拦了。右键 安装.bat →「以管理员身份运行」，
     或者先在 PowerShell 里执行：
     Set-ExecutionPolicy -Scope CurrentUser RemoteSigned


怎么用
------
双击桌面图标，在「目标」里填：
    https://github.com/某某/某某skill      ← Git 仓库
    C:\path\to\skill                      ← 本地文件夹
    某个.zip                              ← 压缩包
然后点「开始扫描」。

结果里：
    0-20   安全，可以装
    21-50  谨慎
    51-80  不要装
    81-100 严重，别装

注意：第一次扫描会慢（要加载分析规则），1-3 分钟很正常，不是卡死。
状态栏有已用时，不想等可以点「停止」。


装到哪儿了
----------
    %LOCALAPPDATA%\SkillSpector\
       app\      界面程序
       engine\   Python 运行环境 + 扫描引擎
       config.json

卸载：双击安装包里的 卸载.bat（或者 %LOCALAPPDATA%\SkillSpector\卸载.bat）
出问题想自查：双击 检查环境.bat，它会逐项告诉你哪里坏了。


说明
----
扫描器本身是 NVIDIA 开源的 skillspector（Apache-2.0）。
界面只是它的一个壳子，规则和判断都来自 skillspector 本身。
静态分析有一定误报率，看到问题别慌，先点进去看「问题片段」和「说明」。
